# OpenClassrooms Projet 5 — Attrition API

API FastAPI de prédiction d'attrition réalisée pour Futurisys.

- `/health` : état public du service ;
- `/docs` : contrat OpenAPI et interface Swagger ;
- `/predict` : prédiction protégée par le header `X-API-Key`.

Le code source et la documentation complète sont disponibles dans le
[dépôt GitHub](https://github.com/hgbe-GH/openclassrooms-projet5).
