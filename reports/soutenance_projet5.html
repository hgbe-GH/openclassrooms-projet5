Projet 5 - Deploiement d'un modele de ML

Support de soutenance concis pour presenter le depot, l'API FastAPI, PostgreSQL, les tests, la CI/CD et le deploiement cible sur Hugging Face Spaces.

Fil conducteur conseille : besoin client, architecture, demo API, persistance PostgreSQL, qualite logicielle, pipeline CI/CD, limites et prochaines etapes.

Message d'ouverture

Probleme

Transformer le modele d'attrition du Projet 4 en service exploitable par une API, testable et deployable.

Reponse

Une API FastAPI documentee, protegee par cle API, avec journalisation PostgreSQL et pipeline GitHub Actions.

Resultat

Un POC industrialisable, relancable localement et presentable en soutenance avec preuves techniques.

Parcours de demo recommande

  • Montrer la racine du depot et [README.md](/home/hgbe/openclassrooms/Projet5/README.md).
  • Presenter POST /predict, GET /health et la documentation Swagger.
  • Executer ou commenter un appel avec header X-API-Key.
  • Montrer la table prediction_logs, le script scripts/create_db.py et le schema BDD.
  • Afficher les tests Pytest, la couverture et le workflow GitHub Actions.

Points techniques a verbaliser

Architecture

Separation claire entre API, prediction, configuration et persistance.

Securite

Cle API via X-API-Key pour proteger les predictions.

Base de donnees

Persistances des entrees/sorties du modele pour la tracabilite.

Qualite

Tests unitaires et integration, lint Ruff, couverture Pytest-Cov.

CI/CD

Workflow GitHub Actions avec PostgreSQL, migrations et preparation du deploiement.

Deploiement

Configuration Docker pour Hugging Face Spaces avec restauration du modele chiffre.

Questions probables et reponses courtes

  • Pourquoi FastAPI ? Parce qu'il combine validation, documentation OpenAPI et mise en service rapide.
  • Pourquoi PostgreSQL ? Pour tracer les appels et conserver les entrees/sorties du modele.
  • Comment la qualite est-elle controlee ? Avec Pytest, tests d'integration, Ruff et un workflow CI.
  • Comment la securite est-elle traitee ? Avec une cle API, des secrets non versionnes et une separation des environnements.
  • Quelles sont les limites ? Le deploiement final depend encore des secrets et variables cibles de l'environnement distant.
